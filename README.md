# 珠宝视觉美学

课程型网站与单款珠宝视觉诊断体验版。四章内容介绍美学判断方法；诊断区根据用户填写的产品事实和销售场景，给出规则化的拍摄及内容建议。

## 本地运行

需要 Node.js 20+ 与 pnpm。执行 `pnpm install --frozen-lockfile`，然后 `pnpm dev`。运行 `pnpm test` 检查诊断规则，`pnpm build` 验证构建，`pnpm start` 预览构建结果。

## 诊断流程

1. 填写产品名称、品类、已核实材质、销售场景、渠道、目标和现有问题。
2. 可选择一张本机图片作为参考预览；图片不会上传，系统也不会识别图片。
3. 阅读规则建议，填写补充修改，并下载文字方案。数据仅保存在当前页面，刷新后会清除。

红宝石、黄宝石、绿宝石三个预设仅供演示，不是真实客户案例，也没有经实物核验。诊断不会调用 AI、生成图片或判断宝石真伪；材质、尺寸、证书和工艺需要人工核验。

## 部署说明

仓库当前没有 `.openai/hosting.json`。构建脚本在缺少该文件时跳过复制，因此可以本地构建；若部署到既有 Sites 项目，应使用该项目原有的 hosting manifest 和项目身份，不能凭空创建项目 ID。`dist/` 是历史上传的构建产物，发布时应以当前源代码重新构建，不应把历史产物当作最新版本。
